# خادم تنبيهات هَدْي (Cloudflare Worker)

**لماذا يلزم؟** المتصفحات تجمّد التطبيقات المغلقة أو في الخلفية، فلا يستطيع التطبيق وحده إيقاظ نفسه عند موعد التنبيه.
هذا الخادم الصغير (مجاني) يرسل «نبضة» Web Push في الموعد، فيستيقظ الجهاز ويعرض التنبيه.
لا يخزّن الخادم عناوين مهامك ولا موقعك؛ فقط أرقام المواعيد وعنوان اشتراك الجهاز.

يُنفَّذ **مرة واحدة** من صاحب التطبيق (أنت)، ثم يستفيد منه كل المستخدمين.

## الخطوات

1. ثبّت Node.js، ثم من داخل مجلد `push-worker`:
   ```
   npm install -g wrangler
   wrangler login
   ```
2. ولّد مفاتيح VAPID (تظهر القيمة السرية في الطرفية، لا ترفعها لأي مستودع):
   ```
   node scripts/gen-vapid.mjs
   ```
3. أنشئ قاعدة البيانات وانسخ `database_id` الذي يظهر إلى ملف `wrangler.toml`:
   ```
   wrangler d1 create hady-push
   wrangler d1 execute hady-push --remote --file=schema.sql
   ```
4. خزّن المفتاح السرّي (الصق السطر JSON الذي طبعه الأمر في الخطوة 2):
   ```
   wrangler secret put VAPID_PRIVATE_JWK
   ```
5. عدّل في `wrangler.toml`: `VAPID_SUBJECT` (بريدك بصيغة `mailto:...`) و`ALLOWED_ORIGIN` (رابط تطبيقك، أو اتركه `*`).
6. انشر:
   ```
   wrangler deploy
   ```
   سيظهر رابط مثل `https://hady-push.اسمك.workers.dev`.
7. ضع الرابط في `web/config.js` ثم ارفع التطبيق من جديد:
   ```js
   window.HadyConfig = { pushUrl: 'https://hady-push.اسمك.workers.dev' };
   ```
8. في التطبيق: الإعدادات ← «التنبيهات في الخلفية» ← **تفعيل** ثم **تجربة في الخلفية**، وأغلق التطبيق وانتظر الدقيقة.

للتحقق من الخادم: افتح `<الرابط>/config` فيظهر `publicKey`.

## حدود يجب معرفتها
- الصوت في الخلفية هو صوت الإشعارات الافتراضي للجهاز؛ الأصوات المخصصة تعمل والتطبيق مفتوح.
- الجدول يُرسل للأيام الأربعة القادمة، فيحتاج التطبيق أن يُفتح مرة كل بضعة أيام.
- آيفون: يلزم تثبيت التطبيق على الشاشة الرئيسية (iOS 16.4 فأعلى).
- أندرويد: استثنِ التطبيق من توفير البطارية لضمان الدقة.
- الخطة المجانية تكفي لمئات المستخدمين؛ كل دقيقة يُعالج الخادم حتى 40 جهازاً مستحقاً.
